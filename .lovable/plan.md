# שליחת פרטי מסיימי/ות הלומדה לגיליון גוגל שיטס

בכל סיום מוצלח של הלומדה (כשמונפקת התעודה), תיווסף שורה חדשה לגיליון גוגל שיטס שלכם.

## מה יירשם בכל שורה

| עמודה | מקור |
|---|---|
| שם מלא | טופס פרטי המשתמש/ת בלומדה |
| אימייל | חשבון מחובר, ואם אין — שדה אימייל חדש שיתווסף לטופס |
| ארגון / בית העסק | טופס פרטי המשתמש/ת |
| תפקיד | טופס פרטי המשתמש/ת |
| תאריך ביצוע | תאריך הנפקת התעודה |
| ציון | ציון הבוחן (מתוך 7) |

## איך זה יעבוד

1. חיבור Google Sheets דרך מסך החיבור של Lovable (כרטיס חיבור יופיע בצ'אט; יש לבחור/ליצור חיבור לחשבון גוגל שמחזיק את הגיליון).
2. אני צריך/ה את כתובת הגיליון (URL) שאליו לכתוב — אפשר לשלוח אותה בהודעה. לחלופין אצור גיליון חדש עם שורת כותרות ואשלח לכם קישור.
3. בעת לחיצה על "הפקת תעודה" בלומדה — ורק אחרי מעבר מוצלח של הבוחן — הלומדה תשלח את פרטי הסיום לאתר, והאתר יוסיף שורה לגיליון.
4. הגנה מפני כפילויות: אם אותו/ה משתמש/ת מפיק/ה תעודה שוב באותו יום, לא תיווסף שורה כפולה.
5. השמירה היא "ברקע": אם השליחה לגיליון נכשלת, התעודה עדיין מוצגת ואין הודעת שגיאה מפריעה — הכשל נרשם ביומן השרת.

## שינויים טכניים

- `public/learner.html`
  - הוספת שדה אימייל לטופס פרטי המשתמש/ת (חובה), שנשמר ב-state המקומי.
  - ב-`generateCertificate()`: שליחת `postMessage` חדש מסוג `hakshava-completion` עם שם, אימייל, ארגון, תפקיד, תאריך ותוצאת הבוחן.
- `src/lib/sheets.functions.ts` (חדש)
  - `logCompletionToSheet` — server function ציבורית עם ולידציית Zod על כל השדות (אורך מקסימלי, פורמט אימייל, ציון 0–7).
  - קריאה ל-Google Sheets API דרך שער החיבורים של Lovable: `POST /google_sheets/v4/spreadsheets/{id}/values/{tab}!A:F:append?valueInputOption=USER_ENTERED`, עם `LOVABLE_API_KEY` ומפתח החיבור מ-`process.env` (שרת בלבד).
  - טיפול בשגיאות: רישום status וגוף התשובה, החזרת `{ ok:false }` ללקוח בלי לחשוף פרטי חיבור.
  - מזהה הגיליון ושם הלשונית נשמרים כקבועים בקוד השרת.
- `src/routes/index.tsx`
  - מאזין ל-`hakshava-completion` (בדיקת origin כמו היום) וקורא ל-server function; שמירה על מנגנון מניעת שליחות כפולות.
